# FPGA CPU Core (Basys 3 Implementation)

A synthesizable SystemVerilog port of a custom 8-bit microcoded CISC CPU architecture, targeted for the Xilinx Artix-7 (Basys 3) FPGA and built to execute bare-metal hardware applications (such as a fully playable Snake game).

This project is the HDL evolution of my 40+ breadboard discrete logic processor:  
🔗 **Hardware Heritage:** [0nonymous/Breadboard-CPU-Computer-System](https://github.com/0nonymous/Breadboard-CPU-Computer-System)

---

## Architectural Highlights

* **SystemVerilog RTL Core:** Complete translation of the original discrete TTL/microcoded architecture into clean, synthesizable HDL.
* **Asynchronous Distributed LUTRAM:** Implemented memory using FPGA Distributed RAM primitives (LUTs) rather than Block RAM (BRAM). This provides single-cycle asynchronous read capability, matching the CPU microarchitecture's timing model without adding pipeline stalls or clock-edge alignment cycles.
* **64KB Address Space:** Retains the 16-bit address bus and 8-bit data bus layout, complete with memory-mapped I/O peripherals.
* **Custom ISA Support:** Fully implements the 70-instruction (0x00–0x45) CISC-style instruction set originally created for the breadboard CPU.
* **On-Board Hardware I/O:** Core logic interfaces directly with memory-mapped peripherals (Basys 3 switches, pushbuttons, LEDs, and 7-segment displays) to drive real-time game states, logic outputs, and user inputs natively on bare-metal silicon.

## CPU Specifications & Datapath

| Specification | Implementation Details |
| :--- | :--- |
| **Architecture Type** | 8-Bit Custom CISC (Loosely 6502-inspired) |
| **Datapath Width** | 8-Bit Data Bus / 16-Bit Address Bus |
| **Registers** | `A` (Accumulator), `B` (Helper), `X` (Index), `SP` (Stack Pointer, descending from `0xFF`), `PC` (16-bit Program Counter), `MAR` (16-bit Memory Address Reg), `IR` (Instruction Reg) |
| **Flags** | Zero (`Z`), Carry (`C`), Negative (`S`) |
| **Target Hardware** | Digilent Basys 3 (Xilinx Artix-7 XC7A35T-1CPG236C) |
| **Toolchain** | Xilinx Vivado |

## Performance & Execution Metrics

* **System Clock:** 250 kHz
* **Throughput:** ~31,250 Instructions Per Second (IPS) (~8 clock cycles per instruction average)
* **Memory Structure:** Distributed LUTRAM to eliminate synchronous BRAM read latency.

## Custom ISA & Assembler Integration

The FPGA CPU consumes machine code generated by the custom two-pass Python assembler built for the original breadboard system. The addressing mode syntax is preserved directly:

* `$` — Immediate (`lda $10`)
* `@` — Absolute (`lda @2000`)
* `#` — Indirect (`lda #3000`)
* `&` — Absolute + X Offset (`lda &4000`)
* *No suffix* — Implied (`inx`)

Assembly programs (including instruction verification routines, Fibonacci, display output drivers, and the fully interactive **Snake** game) compile directly to binary ROM initialization files loaded onto the FPGA. Unchanged binaries run on breadboard CPU and FPGA implementation highlighting how both systems are identical.

## Memory Map & Peripherals

* **Total Address Space:** 64KB (16-bit address bus)
* **Memory Architecture:** Distributed LUTRAM mapped across RAM/ROM address space for asynchronous, zero-wait-state access.
* **I/O Subsystem:** Memory-mapped I/O interfacing through 4 PMODs (32 I/O pins total)
* **Register View:** Onboard switches, LEDs, and 7 segment displays allow for inspecting register contents, addresses, and databus
